JARVIS PC CONTROL — PWA v1.0

1. Откройте firebase-config.js и вставьте точные apiKey и appId из Firebase Console → Project settings → Your apps → Config.
2. Загрузите содержимое папки в корень отдельного репозитория GitHub.
3. Settings → Pages → Deploy from a branch → main / root → Save.
4. Откройте опубликованный HTTPS-адрес и войдите под email/паролем администратора Firebase.
5. Оставьте JARVIS_Agent_TEST.py работающим для PC_1. Остальные ПК будут Offline.
6. Имена записываются в devices/PC_1/name и аналогично для остальных.
7. Кнопки выключения ТОЛЬКО записывают команды с mode=test. Текущий тестовый агент их не выполняет.

ВАЖНО: администраторские пароли не сохраняйте в репозитории. Правила RTDB должны ограничивать запись команд UID администратора. Переименования работают только если текущие Rules разрешают администратору запись devices/$deviceId/name. При ошибке permission_denied проверьте Rules.

Текущая версия не реализует службу Windows или реальное выключение. Не устанавливайте неподтверждённый агент, исполняющий тестовые команды.
