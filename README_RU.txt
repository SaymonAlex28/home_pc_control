JARVIS PC CONTROL 3.0
Загрузите файлы в корень GitHub Pages, заменив старые. Обновите страницу Ctrl+Shift+R. При необходимости удалите старую PWA и установите снова. Если вход не работает, проверьте Console F12 и Firebase Authentication Authorized domains. Не ослабляйте правила RTDB. Команды отправляются только после подтверждения; агент должен разрешать выключение. Статус отсутствия связи не доказывает физическое выключение. Для чтения результатов нужны права чтения command_results/PC_1 и аналогичных узлов.
